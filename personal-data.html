Правила обработки персональных данных

Редакция от 22 октября 2026 года. Правила применяются к обращениям через bamboo.nimtech.ru.

Оператор: Индивидуальный предприниматель Белоусов Николай Владимирович (ИНН 631629072769, ОГРНИП 319631300067247).

1. Категории субъектов и данных

Посетители сайта, потенциальные и действующие клиенты. Обрабатываются предоставленные ими контактные данные, содержание запросов и необходимые сведения о заказе; при использовании сайта — технические данные посещения. Специальные категории и биометрические персональные данные целенаправленно не запрашиваются.

2. Операции с данными

Сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, передача уполномоченным обработчикам при наличии основания, обезличивание, блокирование, удаление и уничтожение.

3. Порядок обработки

Обработка осуществляется автоматизированными средствами и, при необходимости, без их использования. Данные используются только для заявленных целей и в необходимом объёме. Сведения не публикуются и не продаются.

4. Обращения и согласие

Отправляя запрос через формы или каналы связи, посетитель предоставляет сведения для обработки обращения. Если для конкретной обработки требуется согласие, оно должно запрашиваться отдельным понятным действием с возможностью ознакомиться с этой политикой. Согласие на рекламные сообщения оформляется отдельно.

5. Сроки и прекращение обработки

Данные хранятся не дольше необходимого для цели обработки и выполнения обязательных требований законодательства. По достижении цели, при прекращении правовых оснований или по обоснованному требованию данные удаляются, уничтожаются либо обезличиваются в установленные законом сроки.

6. Защита и доступ

Оператор ограничивает доступ к данным, принимает меры по обеспечению их конфиденциальности и безопасности и рассматривает обращения субъектов персональных данных.

7. Права субъекта

Для получения сведений об обработке, исправления, блокирования, удаления данных либо отзыва согласия направьте запрос на оператору по официальным каналам связи. В запросе укажите данные, позволяющие определить, к какому обращению он относится; дополнительные сведения запрашиваются только при необходимости идентификации.
