# NimTech Bamboo

Репозиторий лендинга NimTech Bamboo.

## Развёртывание

Основной сайт — статический `index.html`. Для публикации на Beget загрузите `index.html` в корневую папку домена `nim-tech.ru` и включите HTTPS.

## Сборка

Прототип v1.7 подготовлен как автономный HTML со встроенными изображениями. Сам `index.html` пока необходимо загрузить отдельно. README не означает, что сайт уже опубликован.

Не храните в публичном репозитории пароли, ключи доступа и персональные данные.
